# Kayani Men's Social

A private, mobile-first wellness companion for men (PWA). Tanzania first, English + Kiswahili.

## Stack
- Next.js (App Router, TypeScript) + Tailwind CSS
- Supabase (database, auth, storage) — coming next
- Hosted on Vercel / Netlify

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000 (use your phone-sized browser window).
